☕ Introducción a Ciencias de la Computación con Java

Repositorio donde almaceno los programas, ejercicios y prácticas realizados durante mi aprendizaje de Ciencias de la Computación y programación orientada a objetos con Java.

El contenido está organizado siguiendo el temario del curso, comenzando con los fundamentos de las ciencias de la computación y avanzando progresivamente hacia conceptos de programación más complejos como recursión, herencia, genéricos, interfaces gráficas, programación en red y concurrencia.

🎯 Objetivo del repositorio

Este repositorio funciona como una bitácora de aprendizaje. Cada programa representa un concepto, algoritmo o problema trabajado durante el curso.

La intención no es únicamente almacenar código, sino poder revisar posteriormente cómo fueron implementados y comprender la evolución de mis conocimientos en programación y Ciencias de la Computación.
